NOTES / THINGS TO CHECK BEFORE USING AS TRAINING DATA

1. Block structure: each sheet holds several runs ('ชุดที่ 1', 'ชุดที่ 2'). Data Train B and Train B conductivity have 3 blocks (15 + 25 + 38 rows); the first two are both labeled 'ชุดที่ 1' and both start at Cycle 16.93.
2. Data Train A, block 2 (Excel rows 26-66): header labels were copied from block 1 and are wrong. Real layout: C=Cycle, D=Cond In, E=Cond Out, F=Silica In, G=Silica Out, H=Cond removal %, I=Silica removal %, J=Silica safe, K=Cond safe (the [HEADERS] above show the corrected names).
3. Data Train B, blocks 2 and 3: column K 'Cond. Safe?' uses F<10 (threshold 10) while the header and block 1 use F<0.1. Those TRUE/FALSE values are therefore not comparable with the 0.1 uS/cm limit - recompute from the raw outlet conductivity if you need that label.
4. Train A Conductivity block 2, Percent Load on Resin: rows 29-64 divide by a hard-coded 73.08 instead of the final Ion Load L66 (=73.076...). Difference is tiny but it is not the same formula as rows 27-28 and 65-66.
5. Train B conductivity block 1: E7 (MB inlet conductivity at Cycle 384.08) = 6.26, while Data Train B has 7.26 for the same cycle. Looks like a typo; all calculated columns for that row use 6.26.
6. Train B conductivity K26 and K57 multiply by C (cycle) instead of D (cycle interval). Same value for the first row of a block (D=C), so no numeric impact.
7. Percent Load on Resin = cumulative Ion Load / FINAL cumulative Ion Load of that block x 100 (so the last row is always 100). It is NOT divided by the 1740 mol total capacity.
8. Ion Load for Silica is computed with the same 'NaCl' column labels, but uses the SiO2 molar mass 60.08 and ppb units (see CONSTANTS).
9. Boolean 'Safe?' columns are exported as TRUE/FALSE; empty outlet cells would give an empty string.
